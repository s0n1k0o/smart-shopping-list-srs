# Умный список покупок (Smart Shopping List)

## Описание проекта

«Умный список покупок» — приложение для планирования и организации покупок продуктов питания и товаров повседневного спроса.

Приложение позволяет создавать списки покупок, добавлять товары с указанием количества и единиц измерения, распределять товары по категориям и совместно использовать списки с членами семьи.

## Цель проекта

Разработать удобное приложение, которое упростит процесс подготовки к покупкам, поможет не забывать необходимые товары и позволит членам семьи совместно планировать покупки.

## Основные возможности

- Создание и редактирование списков покупок.
- Добавление и удаление товаров.
- Указание количества товаров.
- Выбор единиц измерения: штуки, килограммы, граммы, литры, миллилитры и упаковки.
- Группировка товаров по категориям.
- Отметка уже купленных товаров.
- Создание семейных групп.
- Совместное использование списков покупок.
- Синхронизация изменений между участниками.

## Основные категории товаров

- Бакалея.
- Молочные продукты.
- Овощи и фрукты.
- Мясо и рыба.
- Хлебобулочные изделия.
- Напитки.
- Бытовая химия.
- Прочее.

## Основные пользователи

- Люди, самостоятельно планирующие покупки.
- Семьи, совместно составляющие списки необходимых товаров.
- Пользователи, желающие контролировать процесс совершения покупок.
